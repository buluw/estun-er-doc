# POLYHEDRON

POLYHEDRON 型变量通过 index 来选择多边体区域（ID）。该变量仅支持在全局用域中创建，删除，修改等操作。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `index` | int | 多边体区域的编号，index 取值范围为 [0, 4]。其中 0 表示该变量无效，其它表示 ID 为 index 的多边体区域。 | — |
| `activate` | bool | 多边体区域是否在激活状态。 | — |
| `isInArea` | bool | 是否在多边体区域内。 | — |
| `note` | string | 变量注释。 | — |
