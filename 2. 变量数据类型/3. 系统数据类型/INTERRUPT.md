# INTERRUPT

存储 INTERRUPT 名称信息，作为中断标识的唯一索引，该变量仅支持在全局变量作用域中创建，删除，修改，复制，粘贴等操作（其中复制、粘贴操作不能跨域和跨工程）。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `value` | string | 存储中断标识的名称信息。 | 在示教器上创建该变量时，变量值会自动同步为变量名。如创建的 INTERRUPT 类型变量名为 Inq，创建后 Inq.value 也为 Inq。 |
| `note` | string | 变量注释。 | — |
