# LsThresh

LsThresh 型变量用来记录各个关节轴的速度区间阙值参数，用来改善机器人在某一速度区间段内的低速抖动现象，与增益比例阙值参数一起搭配使用。设置范围：[10,1000]，单位：$\mathrm { r / m i n }$。该变量只允许在全局域创建以及修改。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `J1` | int | J1 轴对应的速度区间阙值，单位：%。 | — |
| `J2` | int | J2 轴对应的速度区间阙值，单位：%。 | — |
| `J3` | int | J3 轴对应的速度区间阙值，单位：%。 | — |
| `J4` | int | J4 轴对应的速度区间阙值，单位：%。 | — |
| `J5` | int | J5 轴对应的速度区间阙值，单位：$\%$。 | — |
| `J6` | int | J6 轴对应的速度区间阙值，单位：%。 | — |
| `note` | string | 变量注释。 | — |
