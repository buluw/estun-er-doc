# USERCOOR

USERCOOR 型变量用来记录用户坐标系参数，定义用户坐标系相对于世界（基）坐标系的位移和旋转。该参数可由用户根据变量界面标定计算所得，也可由用户自行输入。该变量只允许在全局域创建以及修改。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `id` | int | 用户坐标系的唯一索引编号，该值不可被修改，由创建时系统自动分配。 | — |
| `x` | real | TCP 相对于世界（基）坐标系在 x 方向的位移偏移量，单位是 mm。 | — |
| `y` | real | TCP 相对于世界（基）坐标系在 y 方向的位移偏移量，单位是 mm。 | — |
| `z` | real | TCP 相对于世界（基）坐标系在 z 方向的位移偏移量，单位是 mm。 | — |
| `a` | real | TCP 相对于世界（基）坐标系 z 轴旋转的欧拉角，单位是 deg。 | — |
| `b` | real | TCP 相对于世界（基）坐标系 y’轴旋转的欧拉角，单位是 deg。 | — |
| `c` | real | TCP 相对于世界（基）坐标系 x’’轴旋转的欧拉角，单位是 deg。 | — |
| `note` | string | 变量注释。 系统预定义了世界坐标系 World，其中各个偏移量的值默认都为 0，用户可根据现场需求自行定义需要使用的用户坐标系。 | — |
