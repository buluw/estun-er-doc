# LsScale

LsScale 型变量用来记录各个关节轴的增益比例阙值，配置及使用手册上使用的参数，用来改善机器人在某一速度区间段内的低速抖动现象，与速度区间阙值参数一起搭配使用。该变量只允许在全局域创建以及修改。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `J1` | int | J1 轴对应的增益比例阙值，单位：%。 | — |
| `J2` | int | J2 轴对应的增益比例阙值，单位：%。 | — |
| `J3` | int | J3 轴对应的增益比例阙值，单位：$\%$。 | — |
| `J4` | int | J4 轴对应的增益比例阙值，单位：$\%$。 | — |
| `J5` | int | J5 轴对应的增益比例阙值，单位：%。 | — |
| `J6` | int | 变量注释。 | — |
