# CenterPos

质心矢量是以安装的工具或负载在坐标系 $\mathrm { { O } _ { \mathrm { { T o o l } } } }$ -XYZ 上的位置设定，如下图所示：

工具&负载质量信息参考坐标系方向如下图 1 所示，

![](/images/centerpos-axis-ref.png)

工具&负载质量信息坐标系定义实例如图所示

![](/images/centerpos-example.png)

注：工具和负载的质量信息坐标系均参考图 1 中坐标系 $O_{Tool}$ -XYZ。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `Mx` | real | 安装的工具或装夹的负载在坐标系 $O_{Tool}$ -XYZ 的 X 方向上的偏移量，单位是 mm。 | — |
| `My` | real | 安装的工具或装夹的负载在坐标系 $O_{Tool}$ -XYZ 的 Y 方向上的偏移量，单位是 mm。 | — |
| `Mz` | real | 安装的工具或装夹的负载在坐标系 $O_{Tool}$ -XYZ  的 Z 方向上的偏移量，单位是 mm。 | — |
