# SPEED

用来定义机器人和外部轴的运动速度。为了方便用户使用，系统预设了常用的速度变量（系统变量，不允许用户修改），同时可支持用户自在全局，工程，程序三大变量作用域中对该变量进行创建，删除，修改等操作。

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| `per` | real | 用于指定关节运动指令时的运动速度，适用于 MovJ,MovJRel,MovJSearch 指令，取值范围 $1 \% { \sim } 1 0 0 \%$。 | — |
| `tcp` | real | 定义机器人末端点的线速度,用于 MovL,MovC 等直线圆弧运动指令。 | — |
| `ori` | real | 定义机器人末端点姿态的旋转速度。 | — |
| `exj_l` | real | 定义外部直线轴的运动速度。 | — |
| `exj_r` | real | 定义外部旋转轴的运动速度。 | — |
