# SetMatrixFourPoint 四点设置矩阵

该指令以指定四个点形成空间中的一个四边形，并将这个四边形按照设置的行数和列数进行等分得到一个矩阵点组。

## 指令格式

SetMatrixFourPoint(P1, P2, P3, P4, Row, Column)
SetMatrixFourPoint(原点, 行方向最后点, 列方向最后点, 原点对角点, 行数, 列数)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| P1 | CPOS 变量 | 指定平行四边形的第一个点，也称为原点。 | |
| P2 | CPOS 变量 | 指定平行四边形的行方向上的最后一个点。 | |
| P3 | CPOS 变量 | 指定平行四边形的列方向上的最后一个点。 | |
| P4 | CPOS 变量 | 指定平行四边形的原点对角点。 | |
| Row | int | 生成矩阵的行数。 | |
| Column | int | 生成矩阵的列数。 | |

## 应用示例

将 P1、P2、P3、P4 形成的四边形按照 4 行 5 列均分：

```estun
SetMatrixFourPoint(P1, P2, P3, P4, 4, 5)
```

**逻辑解析**：
以 P1、P2、P3、P4 四个点构成四边形，并按 4 行 5 列等分生成矩阵点组。
