# SetAO 设置模拟量输出

模拟量输出设置指令用于控制机器人控制器的模拟输出端口，输出连续变化的电压信号。该指令常用于控制变频器速度、比例阀压力或激光器功率等需要连续调节的外部设备。

## 指令格式

`SetAO (AOUT, VALUE)`

`SetAO (模拟量输出, 目标值)`

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| AOUT | AO | 待设置的模拟量输出端口变量 | 必填 |
| VALUE | real 或 REAL 变量 | 设置模拟量端口的电压值，范围 **-10.0 ~ 10.0**（单位：V） | 必填 |

---

## 应用示例

**示例 1：设置固定电压**

将 AO1 端口的输出电压设定为 5.0V。

```estun
SetAO (AO1, 5.0)
/* 设置与 AO1 绑定的端口电压为 5.0V */
```

**示例 2：动态调节**

通过变量实时调整输出电压（例如根据工艺需求调整激光功率）。

```estun
REAL0 = 7.5
SetAO (AO2, REAL0)
/* 将 AO2 端口输出切换为 7.5V */
```
