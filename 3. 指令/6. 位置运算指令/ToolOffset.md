# ToolOffset 工具坐标系偏移

通过对基准工具进行旋转或偏移，生成新的工具坐标系。

## 指令格式
ToolOffset(F1, P, F2)
ToolOffset(基准工具参数, 偏移量, 目标工具参数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| F1 | TOOL | 基准工具参数（Tool1），转换前的基准工具坐标系参数。 | |
| P | DCPOS | 偏移量（offset），新工具坐标系相对于原始工具参数的偏移量。 | |
| F2 | TOOL | 目标工具参数（Tool2），偏移后获得的新工具参数。 | |

---
## 应用示例
**示例 1：**
```estun
ToolOffset (TOOL1, DCPOS1, TOOL2)
//根据工具坐标系 TOOL1、偏移量 DCPOS1，得到新的工具坐标系 TOOL2。
```
