# ReceiveWObj 设置工件接收状态

该指令为设置工件数据的接收状态指令，通过组合使用该指令可以让机器人系统在某一段轨迹内不接收视觉或 run 程序中发来的工件位置信息，避免出现误跟随的情况，满足不同的现场工艺。

## 指令格式

ReceiveWObj(Coord, enableSts)

ReceiveWObj(坐标系, 使能接收状态)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| Coord | SYNCOORD 变量 | 当前工件位置信息所参考的动坐标系，需与传送带配置界面中启用的动坐标系一致 | 必填 |
| enableSts | enum | 使能机器人系统对工件位置信息的接收状态：<br>OFF—关闭接收<br>ON—开启接收 | 必填 |
