# ResetWObjBuf 复位工件数据队列

该指令为复位已接收到的工件数据队列指令，可以将队列中从外部接收到且未被执行的工件信息清空。

## 指令格式

ResetWObjBuf(Coord, [ResetType], id)

ResetWObjBuf(坐标系, [复位类型], 视觉 ID 号)

*(备注：带 [] 参数为可选参数)*

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| Coord | SYNCOORD 变量 | 当前工件位置信息所参考的动坐标系，需与传送带配置界面中启用的动坐标系一致 | 必填 |
| [ResetType] | enum | 对队列中数据的复位类型：<br>ALL—将队列中已接收到的数据全部清除<br>SELECT—将队列中与复位的视觉 ID 号一致的数据全部清除<br>CURRENT—将队列中的第一个数据清除<br>DEFAULT—缺省类型 | 可选，默认 ALL |
| id | int | 队列中需要被复位的 ID 号。仅当 ResetType 设为 SELECT 时该参数才有效 | 必填 |
