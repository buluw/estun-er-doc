# removeStr 删除指定位置

removeStr 为字符串删除指令，去掉指定位置的字符串，并将修改过后的字符串数据返回。

## 指令格式

removeStr(str, start, count)

removeStr(源字符串, 起始位置, 删除数量)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| str | string | 待删除的字符串变量或常量 |—|
| start | int | 待删除的起始位置 |—|
| count | int | 待删除的字符数量 |—|

**函数返回值**：截取后的字符串，string 型常量。
