# sub 截取子字符串

sub 为字符串截取指令，截取某一段区间内的字符串数据，并将截取后的数据返回。

## 指令格式

sub(str, start, end)

sub(源字符串, 起始位置, 结束位置)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| str | string | 待截取的字符串变量或常量 | — |
| start | int | 待截取的起始位置 | — |
| end | int | 待截取的结束位置 | — |

**函数返回值**：截取后的字符串，string 型常量。
