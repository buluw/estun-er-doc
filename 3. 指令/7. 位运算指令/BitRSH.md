# BitRSH 按位右移

将操作数1进行按位右移（Right Shift）运算，移动位数为操作数2的值，结果赋值给第一个操作数。

## 指令格式
BitRSH(I1, I2)
BitRSH(操作数1, 移动位数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| I1 | INT | 操作数1（data1），需要操作的数据，运算结果也赋值到该操作数。 | |
| I2 | INT | 操作数2（data2），指定要右移的位数。 | |

---
## 应用示例
**示例 1：**
```estun
BitRSH (INT1, INT2)
//将 INT1 进行按位右移运算（位移量为 INT2），并将结果赋值给 INT1。
```
