# BitAnd 按位与

将两个操作数进行按位与（AND）运算，并将结果赋值给第一个操作数。

## 指令格式
BitAnd(I1, I2)
BitAnd(操作数1, 操作数2)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| I1 | INT | 操作数1（data1），需要操作的数据，运算结果也赋值到该操作数。 | |
| I2 | INT | 操作数2（data2），需要比较的数据。 | |

---
## 应用示例
**示例 1：**
```estun
BitAnd (INT1, INT2)
//将 INT1 和 INT2 进行按位与的运算，并将结果赋值给 INT1。
```
