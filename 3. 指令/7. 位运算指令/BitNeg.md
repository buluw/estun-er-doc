# BitNeg 按位取反

将操作数进行按位取反（NOT）运算，并将结果赋值给该操作数。注意：取反操作仅针对操作数的后16位。

## 指令格式
BitNeg(I1)
BitNeg(操作数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| I1 | INT | 操作数（data），需要操作的数据，运算结果也赋值到该操作数。 | |

---
## 应用示例
**示例 1：**
```estun
BitNeg (INT1)
//将 INT1 进行按位取反的运算，并将结果赋值给 INT1。
```
