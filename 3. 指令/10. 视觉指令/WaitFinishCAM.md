# WaitFinishCAM 等待相机拍摄完成

等待相机拍摄完成的指令。

## 指令格式
WaitFinishCAM (wt, id)
WaitFinishCAM (等待时间, 相机索引参数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| wt | int | 等待相机拍照完成的时间，取值范围为 **0-20000ms**。 |  |
| id | int | 指定相机的索引编号。 |  |
---
## 应用示例
**示例 1：**
```estun
WaitFinishCAM (1000, 1)
//等待 1 号相机拍照完成，超时时间为 1000ms。
```
