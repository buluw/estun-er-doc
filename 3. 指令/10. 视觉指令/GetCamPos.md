# GetCamPos 获取相机目标位置

获取相机识别到的目标位置点。

## 指令格式
GetCamPos (P, tarID, ret, id)
GetCamPos (目标位置, 目标 ID, 有效性结果, 相机索引参数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| P | CPOS | 目标位置：相机识别并获取到的目标位置。 |  |
| tarID | INT | 目标 ID：目标物体的识别 ID 值。 |  |
| ret | INT | 有效性：返回获取的位置点是否有效（通常 1 为有效，0 为无效）。 |  |
| id | int | 相机索引参数：指定相机的索引编号。 |  |
---
## 应用示例
**示例 1：**
```estun
GetCamPos (P6, INT0, INT1, 1)
//从 1 号相机获取物体 INT0 的位置并存入 P6，有效性结果存入 INT1。
```
