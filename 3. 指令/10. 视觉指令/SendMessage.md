# SendMessage 发送自定义消息

发送自定义字符串消息，常用于 3D 视觉系统或特定协议的相机通讯。

## 指令格式
SendMessage (msg, id)
SendMessage (信息内容, 相机索引参数)

---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| msg | string | 需要发送给相机的字符串指令。 |  |
| id | int | 指定相机的索引编号。 |  |
---
## 应用示例
**示例 1：**
```estun
SendMessage ("OK", 1)
//向 1 号相机发送字符串消息"OK"。
```
