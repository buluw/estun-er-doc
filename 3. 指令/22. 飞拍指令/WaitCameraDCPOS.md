# WaitCameraDCPOS 获取视觉目标位置

该指令用于获取视觉传输过来的目标相对位置。

## 指令格式

WaitCameraDCPOS(WTime, Vision, TP, tagID, Ret)
WaitCameraDCPOS(等待时间, 相机索引号, 目标相对位置, 目标物体ID, 有效性)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| WTime | int | 执行等待时所需的时间，单位为 ms。值为 0 时默认不等待。 | |
| Vision | int | 相机索引号。 | |
| TP | DCPOS 变量 | 目标相对位置，相对于参考位置的位置增量。 | |
| tagID | INT | 目标物体的 ID 值。 | |
| Ret | INT | 获取的目标相对位置是否有效。返回 1 表示成功，0 表示无效，-1 表示未获取到偏移点超时退出，-2 表示当前超时时间为 0 且未获取到偏移点。 | |

## 应用示例

```estun
WaitCameraDCPOS(10000, 0, DCPOS0, INT0, INT1)
```

**逻辑解析**：
循环等待 10 秒，直到获取到相机传输的目标相对位置。
