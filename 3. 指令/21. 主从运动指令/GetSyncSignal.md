# GetSyncSignal 获取同步信号

该指令用于使从机器人获取到主机器人已执行到指定行的索引信息，便于该从机器人根据该索引信息做出对应的功能操作。

## 指令格式

GetSyncSignal(SyncId, SignalId)
GetSyncSignal(协同标识, 信号索引)

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| SyncId | SYNCID 变量 | 机器人协同标识 ID 号，用于本机与协同机器人之间进行协同校验，主从机器人 ID 一致时才为有效协同。 | |
| SignalId | INT 变量 | 机器人信号索引值，当从机器人执行到该指令时，根据协同标识来获取主机器人所发出的信号索引值，并赋值给该变量。 | |
