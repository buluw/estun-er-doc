# IF 条件判断

该指令用于条件判断表达式跳转控制。当条件判断表达式结果为真时，程序执行 IF 下程序块的内容。每一个 IF 指令必须以关键字 **ENDIF** 作为条件判断程序块的结束。

## 指令格式
IF(condition) THEN ... ENDIF
IF(条件表达式) THEN ... ENDIF
*(备注：带 [] 参数为可选参数)*
---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| condition | bool 表达式 | 条件判断表达式，结果为真时执行 IF 程序块 | 无 |
---
## 应用示例
**示例 1：**
```estun
IF x>1 and y == 1 or z < 1 THEN
    y = 10
ENDIF
```

满足 IF 条件表达式，触发执行"y = 10"，否则 ENDIF 退出。
