该指令用于建立一个表达式，给某个变量赋值。此指令可以执行变量、常量、函数等混合运算赋值。

## 指令格式
Variable = Expression
变量 = 表达式
*(备注：带 [] 参数为可选参数)*
---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| Variable | 任意可赋值类型 | 被赋值的变量 | 无 |
| Expression | 表达式 | 变量、常量、函数等的混合运算表达式 | 无 |
---
## 应用示例
**示例 1：**
```estun
X = Y + Z + 1
```
