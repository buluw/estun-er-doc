# RUN 并行运行

该指令用于程序的并行运行，使机器人能够在运行当前程序的同时运行其他程序（程序必须在同一个工程下）。当前程序继续正常运行，启动一个线程执行另一个程序。

## 指令格式
RUN(ProgramName)
RUN(程序名)
*(备注：带 [] 参数为可选参数)*
---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| ProgramName | string | 要并行运行的程序名称 | 无 |
---
## 应用示例
**示例 1：**
```estun
RUN program1
```

**注：** 系统目前支持同时 RUN 八个并行程序（除主运行程序外），且 RUN 程序中不可以执行运动相关的指令。
