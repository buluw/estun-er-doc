# CALL 调用程序

该指令用于调用同一工程下的另一个子程序，当前程序跳转至子程序执行，子程序执行完后自动跳转回当前程序继续执行。

## 指令格式
CALL(ProgramName)
CALL(程序名)
*(备注：带 [] 参数为可选参数)*
---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| ProgramName | string | 被调用的子程序名称 | 无 |
---
## 应用示例
**示例 1：**
```estun
CALL program1
//跳转到程序 program1 内执行，执行完成后，跳转回当前程序，继续执行
```
