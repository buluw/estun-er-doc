# ELSE 条件判断否则

该指令用于与 IF 指令联合使用，表示 IF 条件判断不成立时将执行的语句块。

## 指令格式
ELSE
ELSE
---

## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| 无 | - | ELSE 为流程控制关键字，无独立参数 | 需与 IF/ENDIF 配合使用 |
---
## 应用示例
**示例 1：**
```estun
IF x>1 and y == 1 or z < 1 THEN
    y = 10
ELSE
    y = 20
ENDIF
```

满足 IF 条件表达式，触发执行"y = 10"，否则执行"y = 20"，ENDIF 退出。
