# ELSIF 条件判断否则如果

该指令用于依赖于 IF 指令，紧跟 IF 指令块后，当 IF 逻辑不成立时进行 ELSIF 逻辑判断。

## 指令格式
ELSIF(condition)
ELSIF(条件表达式)
*(备注：带 [] 参数为可选参数)*
---
## 参数详细说明
| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| condition | bool 表达式 | 条件判断表达式，语法与 IF 表达式相同 | 无 |
---
## 应用示例
**示例 1：**
```estun
IF x>1 and y == 1 or z < 1 THEN
    y = 10
ELSIF x <1 THEN
    y = 20
ENDIF
```

满足 IF 条件表达式，触发执行"y = 10"，否则继续检查，满足 ELSIF 条件表达式，触发执行"y = 20"，ENDIF 退出。
