# MovJSearch 关节寻位

寻位指令（MovJSearch）是指在执行该关节运动指令的过程中，实时进行 **IO 信号检测**或**轴力矩检测**。一旦满足设定的触发条件，机器人将立即（或减速）停止当前运动，记录当前位置，并直接跳转执行后续指令。

**注意：该指令会打断路径的过渡效果。**

## 指令格式

MovJSearch(P, [V], [B], [C], [Tool], [Coord], [PayLoad], Type, Number, Value, [StopType], [StopDecScale], R, [SearchP], [Goto], [DO])

MovJSearch(目标点, [速度], [平滑], [姿态], [工具], [坐标系], [负载], 搜索类型, 端口号, 触发值, [停止方式], [减速比例], 结果变量, [搜索点记录], [跳转行号], [端口输出])

*(备注：带 [] 参数为可选参数)*

---

## 参数详细说明

| 参数 | 类型 | 说明 | 默认值/备注 |
|------|------|------|------------|
| P | APOS 或 CPOS 变量 | 机器人计划运动到的终点。 | 必填 |
| [V] / [B] / [C] / [Tool] / [Coord] / [PayLoad] | - | 与 `MovJ` 指令定义一致（速度、过渡类型、过渡值、工具、坐标系、负载）。 | 过渡类型默认 FINE |
| Type | enum | 检测类型：<br>`DITrig`：物理数字输入口触发。<br>`AITrig`：物理模拟量输入口触发。<br>`SIMDITrig`：虚拟数字输入口触发。<br>`SIMAITrig`：虚拟模拟量输入口触发。<br>`TorqTrig`：力矩触发。 | 必填 |
| Number | int | 检测的编号。若为 `DITrig`，则为**输入口号**；若为 `TorqTrig`，则为**轴编号**。 | 必填 |
| Value | real | 检测的阈值。若为 `DITrig`，则为**电平状态（0 或 1）**；若为 `TorqTrig`，则为**轴额定转矩的千分比**。 | 必填 |
| [StopType] | enum | 停止类型：<br>`HARDSTOP`：立即停止（默认值）。<br>`SOFTSTOP`：减速停止。<br>`DEFAULT`：缺省类型。 | 可选，默认 HARDSTOP |
| [StopDecScale] | real | 仅在 `SOFTSTOP` 时有效，值越大减速越快。 | 可选 |
| R | INT 变量 | 返回值：<br>`0`：未触发条件，正常运动到终点结束。<br>`1`：运动过程中满足条件触发。<br>`2`：在运动起点处就已经满足条件。 | 必填 |
| [SearchP] | APOS | 返回满足触发条件那一时刻，机器人的真实坐标位置。 | 可选 |
| [Goto] | label | 若未触发信号（即 R=0），程序将跳转到指定的标签处执行。缺省则不跳转。 | 可选 |
| [DO] | string | 指令执行完后可触发的额外 IO 操作。 | 可选 |

---

## 应用示例

**示例 1：数字输入触发寻位**



```estun
MovJ(P1, V50, "RELATIVE", C100)
MovJSearch(P2, V50, "RELATIVE", C100, "DITrig", 16, 1, INT0)
MovJ(P3, V50, "RELATIVE", C100)
```

1. 机器人以 50 速度向 P1 运动。
2. 随后向 P2 运动，期间实时监控 **16 号输入口**。
3. 如果 16 号口变为**高电平 (1)**：机器人立即停止向 P2 运动，将 `INT0` 设为 1，直接开始向 P3 运动。
4. 如果运动到 P2 依然没有高电平：机器人到达 P2 后将 `INT0` 设为 0，继续向 P3 运动。
